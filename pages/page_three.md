# Major
## Project for your major

### 1. What the project is, what it does, and who made it

Zotero is a free tool for collecting, organising and citing sources. It was created by the Roy Rosenzweig Center for History and New Media at George Mason University.

### 2. How it would help in your major, with one concrete example task

I can use Zotero to organise academic papers, EU documents and other sources for my master's thesis.

### 3. The five checks from week 41

#### 1. Licence: which one, and what it lets you do

Zotero uses the GNU AGPL v3 licence. It allows you to use, modify and share the software.

#### 2. Last change: when was the latest commit?

The exact latest commit date can be found here:

[Zotero GitHub repository](https://github.com/zotero/zotero)

#### 3. People: how many contributors?

Around 90 contributors.

#### 4. Questions: are issues answered?

Yes, users can get help through the official support forum:

[Zotero Support Forum](https://forums.zotero.org)

#### 5. Money: who funds it?

Zotero is funded through subscriptions (for example, if you want more than 2 GB of storage), donations and grants.

### 4. Your verdict: would you rely on it for a thesis? Could you leave it again if you had to?

Yes, I would rely on Zotero because it makes organising sources easier. If I stopped using it, I could export my references and use them in another programme.
